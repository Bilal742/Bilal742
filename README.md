# 👋 Hi, I'm Muhammad Bilal

**Frontend Developer | Aspiring MERN Stack Developer** 💻🚀  

I began my **Web Development journey in 2024**.  
At that time, I didn’t know anything about coding — but I had a strong passion for it.  
So, I started learning by watching YouTube tutorials and practicing consistently.

I first learned **HTML**, which felt easy and interesting,  
then moved on to **CSS**, which made my projects look beautiful.  
After that came **JavaScript** — everyone told me it was difficult,  
but I proved them wrong 💪 by learning it step by step with dedication.

Later, I joined **Sir Adamjee Institute**,  
where I enrolled in a **Web & App Development course**.  
There, I revised HTML, CSS, and JavaScript —  
and then learned **Tailwind CSS** and **React**, which opened up a new world for me.

I also explored **Backend Development** with **Node.js, Express.js, and MongoDB**,  
and now I’m learning **TypeScript** and **Next.js** to expand into modern web development.
